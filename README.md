# 🎓 Student Grade Management System

A SQL project for managing student records, courses, and grades in a university setting.

## Features
- Student enrollment tracking
- Course and instructor management
- Grade recording and GPA calculation
- Performance analytics with views and stored procedures

## How to Run
1. Open any SQL client (MySQL Workbench, pgAdmin, DBeaver, etc.)
2. Run `schema.sql` first to create the database and tables
3. Run `seed_data.sql` to populate sample data
4. Explore `queries.sql` for useful queries and analytics

## Tech Stack
- SQL (MySQL compatible)
- Relational database design
- Views, stored procedures, triggers
